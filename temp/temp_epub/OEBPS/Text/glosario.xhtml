Glosario de Términos y Acrónimos

Este glosario contiene los términos técnicos más importantes y los acrónimos utilizados en el campo de las redes de datos y las telecomunicaciones, especialmente aquellos relevantes para la certificación CompTIA Network+.

Acrónimos

ACL (Access Control List)
Lista de Control de Acceso. Conjunto de reglas que definen qué usuarios o sistemas tienen acceso a recursos específicos en una red y qué operaciones pueden realizar.
ADSL (Asymmetric Digital Subscriber Line)
Línea de Abonado Digital Asimétrica. Tecnología de transmisión de datos que utiliza líneas telefónicas de cobre para proporcionar宽带 (banda ancha) de alta velocidad, con mayor ancho de banda de descarga que de subida.
AP (Access Point)
Punto de Acceso. Dispositivo que permite a dispositivos inalámbricos conectarse a una red cableada mediante tecnologías Wi-Fi.
ARP (Address Resolution Protocol)
Protocolo de Resolución de Direcciones. Protocolo de la capa de red utilizado para mapear direcciones IP a direcciones MAC en una red local.
ATM (Asynchronous Transfer Mode)
Modo de Transferencia Asíncrona. Tecnología de red de alta velocidad que transmite datos en celdas de tamaño fijo (53 bytes), optimizada para voz, video y datos.
BGP (Border Gateway Protocol)
Protocolo de Pasarela de Frontera. Protocolo de enrutamiento utilizado para intercambiar información de enrutamiento entre sistemas autónomos en Internet.
BIOS (Basic Input/Output System)
Sistema Básico de Entrada/Salida. Firmware almacenado en un chip de la placa base que inicializa el hardware durante el arranque del sistema.
BOOTP (Bootstrap Protocol)
Protocolo de Arranque. Protocolo de red utilizado para asignar direcciones IP a dispositivos sin disco duro durante el arranque.
CIDR (Classless Inter-Domain Routing)
Enrutamiento Inter-Dominios sin Clases. Método de asignación de direcciones IP y enrutamiento que reemplaza el sistema de clases tradicional (A, B, C).
CIFS (Common Internet File System)
Sistema de Archivos de Internet Común. Protocolo de compartilhamento de archivos que permite a aplicaciones acceder a archivos remotos en una red.
DHCP (Dynamic Host Configuration Protocol)
Protocolo de Configuración Dinámica de Host. Protocolo de red que asigna automáticamente direcciones IP y otros parámetros de configuración a dispositivos en una red.
DIMM (Dual In-Line Memory Module)
Módulo de Memoria en Línea Dual. Tipo de módulo de memoria RAM utilizado en computadoras personales y servidores.
DNS (Domain Name System)
Sistema de Nombres de Dominio. Sistema de bases de datos distribuidas que traduce nombres de dominio legibles por humanos a direcciones IP numéricas.
DOCSIS (Data Over Cable Service Interface Specification)
Especificación de Interfaz de Servicios de Datos sobre Cable. Estándar que define los requisitos de comunicación y operación para módems de cable.
DSL (Digital Subscriber Line)
Línea de Abonado Digital. Tecnología de transmisión de datos que permite altas velocidades sobre líneas telefónicas de cobre existentes.
DSSS (Direct Sequence Spread Spectrum)
Espectro Expandido de Secuencia Directa. Técnica de modulación utilizada en comunicaciones inalámbricas que spreads la señal sobre un amplio rango de frecuencias.
EFS (Encrypting File System)
Sistema de Archivos Cifrado. Característica de seguridad de Windows que permite cifrar archivos y carpetas a nivel del sistema de archivos.
EIA (Electronic Industries Alliance)
Alianza de Industrias Electrónicas. Organización que desarrolla estándares para la industria electrónica, incluyendo estándares de cableado de red.
EIGRP (Enhanced Interior Gateway Routing Protocol)
Protocolo de Enrutamiento de Puerta de Enlace Interior Mejorado. Protocolo de enrutamiento propietario de Cisco que combina las ventajas de distancia-vector y estado-enlace.
FHRP (First Hop Redundancy Protocol)
Protocolo de Redundancia del Primer Salto. Protocolos que proporcionan redundancia de puerta de enlace predeterminada en redes IP.
FQDN (Fully Qualified Domain Name)
Nombre de Dominio Completamente Calificado. Nombre de dominio completo que especifica la posición exacta de un nodo en el árbol jerárquico del DNS.
FTP (File Transfer Protocol)
Protocolo de Transferencia de Archivos. Protocolo de red utilizado para transferir archivos entre un cliente y un servidor en una red TCP/IP.
GBIC (Gigabit Interface Converter)
Convertidor de Interfaz Gigabit. Transceptor modular caliente que permite interconectar diferentes tipos de medios en un puerto de red.
GFS (Gluster File System)
Sistema de Archivos Gluster. Sistema de archivos distribuido de código abierto que permite escalar hasta petabytes de almacenamiento.
GPS (Global Positioning System)
Sistema de Posicionamiento Global. Sistema de navegación por satélite que proporciona ubicación y hora en cualquier lugar de la Tierra.
GRE (Generic Routing Encapsulation)
Encapsulación Genérica de Enrutamiento. Protocolo de túnel que encapsula una amplia variedad de tipos de paquetes de red dentro de paquetes IP.
HBA (Host Bus Adapter)
Adaptador de Bus del Host. Placa de circuito que conecta un sistema host a dispositivos de almacenamiento y redes de área de almacenamiento (SAN).
HDLC (High-Level Data Link Control)
Control de Enlace de Datos de Alto Nivel. Protocolo de capa de enlace de datos utilizado en comunicaciones punto a punto y multipunto.
HTTP (HyperText Transfer Protocol)
Protocolo de Transferencia de Hipertexto. Protocolo de la capa de aplicación utilizado para transferir documentos hipermedia como páginas web.
HTTPS (HyperText Transfer Protocol Secure)
Protocolo de Transferencia de Hipertexto Seguro. Versión encriptada de HTTP que utiliza SSL/TLS para seguridad en la transmisión de datos.
HVAC (Heating, Ventilation, and Air Conditioning)
Calefacción, Ventilación y Aire Acondicionado. Sistemas utilizados para controlar las condiciones ambientales en centros de datos.
IaaS (Infrastructure as a Service)
Infraestructura como Servicio. Modelo de computación en la nube que proporciona recursos de infraestructura virtualizados a través de Internet.
ICMP (Internet Control Message Protocol)
Protocolo de Mensajes de Control de Internet. Protocolo de la capa de red utilizado para enviar mensajes de error y información operativa sobre condiciones de red.
IDF (Intermediate Distribution Frame)
Marco de Distribución Intermedio. Armario de telecomunicaciones que contiene equipos de conexión para cables que provienen del MDF.
IDS (Intrusion Detection System)
Sistema de Detección de Intrusiones. Sistema que monitorea el tráfico de red para detectar actividades maliciosas y generar alertas.
IETF (Internet Engineering Task Force)
Grupo de Trabajo de Ingeniería de Internet. Organización internacional que desarrolla y promueve estándares de Internet.
IGMP (Internet Group Management Protocol)
Protocolo de Gestión de Grupos de Internet. Protocolo utilizado por hosts y enrutadores IP para establecer membresías en grupos de multidifusión.
IGP (Interior Gateway Protocol)
Protocolo de Puerta de Enlace Interior. Protocolos de enrutamiento utilizados dentro de un sistema autónomo (OSPF, RIP, EIGRP).
IKE (Internet Key Exchange)
Intercambio de Claves de Internet. Protocolo utilizado para establecer asociaciones de seguridad en VPNs basadas en IPsec.
IMAP (Internet Message Access Protocol)
Protocolo de Acceso a Mensajes de Internet. Protocolo de correo electrónico que permite a los clientes recuperar correos electrónicos de un servidor.
IoT (Internet of Things)
Internet de las Cosas. Red de dispositivos físicos equipados con sensores, software y conectividad para recopilar e intercambiar datos.
IP (Internet Protocol)
Protocolo de Internet. Protocolo de la capa de red responsable de direccionamiento y enrutamiento de paquetes de datos entre hosts.
IPS (Intrusion Prevention System)
Sistema de Prevención de Intrusiones. Sistema que monitorea el tráfico de red y puede tomar medidas para bloquear amenazas detectadas.
IPsec (Internet Protocol Security)
Seguridad del Protocolo de Internet. Suite de protocolos utilizada para asegurar las comunicaciones IP mediante autenticación y cifrado.
IPv4 (Internet Protocol version 4)
Versión 4 del Protocolo de Internet. Versión del protocolo IP que utiliza direcciones de 32 bits, limitando el espacio de direcciones a aproximadamente 4.3 mil millones de direcciones.
IPv6 (Internet Protocol version 6)
Versión 6 del Protocolo de Internet. Versión del protocolo IP que utiliza direcciones de 128 bits, proporcionando un espacio de direcciones significativamente mayor que IPv4.
IS-IS (Intermediate System to Intermediate System)
Sistema Intermedio a Sistema Intermedio. Protocolo de enrutamiento de estado-enlace utilizado para enrutar paquetes dentro de un sistema autónomo.
ISO (International Organization for Standardization)
Organización Internacional de Normalización. Organización internacional que desarrolla estándares internacionales, incluyendo el modelo OSI.
ISP (Internet Service Provider)
Proveedor de Servicios de Internet. Empresa que proporciona servicios de acceso a Internet a usuarios y organizaciones.
ITU (International Telecommunication Union)
Unión Internacional de Telecomunicaciones. Organismo de las Naciones Unidas responsable de cuestiones de tecnologías de la información y comunicación.
LACP (Link Aggregation Control Protocol)
Protocolo de Control de Agregación de Enlaces. Protocolo que permite combinar múltiples enlaces físicos en un único enlace lógico para aumentar el ancho de banda y la redundancia.
LAMP (Linux, Apache, MySQL, PHP/Perl/Python)
Pila de software de código abierto que comprende el sistema operativo Linux, el servidor web Apache, la base de datos MySQL y el lenguaje de programación PHP.
LAN (Local Area Network)
Red de Área Local. Red que conecta dispositivos dentro de un área geográfica limitada, como un edificio o campus.
LDAP (Lightweight Directory Access Protocol)
Protocolo Ligero de Acceso a Directorios. Protocolo utilizado para acceder y mantener servicios de directorio distribuidos.
LLC (Logical Link Control)
Control de Enlace Lógico. Subcapa superior de la capa de enlace de datos en el modelo OSI, responsable del control de errores y flujo.
LLDP (Link Layer Discovery Protocol)
Protocolo de Descubrimiento de Capa de Enlace. Protocolo de capa de enlace que permite a los dispositivos de red anunciar información sobre ellos mismos a dispositivos vecinos.
MAC (Media Access Control)
Control de Acceso al Medio. Subcapa inferior de la capa de enlace de datos responsable del direccionamiento y control de acceso al medio físico.
MAN (Metropolitan Area Network)
Red de Área Metropolitana. Red que cubre un área geográfica más grande que una LAN pero más pequeña que una WAN, típicamente una ciudad.
Mbps (Megabits per second)
Megabits por segundo. Unidad de medida de la velocidad de transmisión de datos, equivalente a un millón de bits por segundo.
MDF (Main Distribution Frame)
Marco de Distribución Principal. Armario de telecomunicaciones principal que sirve como punto de terminación para todos los cables de entrada del edificio.
MIB (Management Information Base)
Base de Información de Gestión. Colección de información organizada jerárquicamente que se utiliza para la gestión de dispositivos de red mediante protocolos como SNMP.
MIMO (Multiple Input Multiple Output)
Múltiple Entrada Múltiple Salida. Tecnología utilizada en comunicaciones inalámbricas que utiliza múltiples antenas en transmisores y receptores.
MMF (Multimode Fiber)
Fibra Multimodo. Tipo de fibra óptica diseñada para transportar múltiples modos de luz, utilizada principalmente para distancias cortas.
MPLS (Multiprotocol Label Switching)
Conmutación de Etiquetas Multiprotocolo. Técnica de conmutación que dirige datos de un nodo a otro utilizando etiquetas cortas en lugar de direcciones IP largas.
MRV (Multiple Request Validation)
Validación de Múltiples Solicitudes. Técnica utilizada para verificar que múltiples solicitudes de recursos provienen de fuentes legítimas.
MSDP (Multicast Source Discovery Protocol)
Protocolo de Descubrimiento de Fuentes de Multidifusión. Protocolo utilizado para compartir información sobre fuentes de multidifusión entre dominios de enrutamiento.
MTU (Maximum Transmission Unit)
Unidad de Transmisión Máxima. Tamaño máximo del paquete de datos que puede transmitirse a través de una red sin fragmentación.
NAC (Network Access Control)
Control de Acceso a la Red. Enfoque de seguridad que implementa un conjunto de protocolos y políticas para asegurar que solo dispositivos autorizados accedan a la red.
NAC (Network Authentication Combo)
Combo de Autenticación de Red. Método que combina múltiples factores de autenticación para verificar la identidad de usuarios en una red.
NAT (Network Address Translation)
Traducción de Direcciones de Red. Técnica que modifica las direcciones IP en los paquetes mientras atraviesan un dispositivo de enrutamiento.
NCP (Network Control Protocol)
Protocolo de Control de Red. Protocolo utilizado para establecer y configurar diferentes protocolos de capa de red sobre una conexión PPP.
NFS (Network File System)
Sistema de Archivos de Red. Protocolo de sistema de archivos distribuido que permite a un usuario en una máquina cliente acceder a archivos en una máquina remota.
NIC (Network Interface Card)
Tarjeta de Interfaz de Red. Hardware de computadora que conecta una computadora a una red y permite la transmisión y recepción de datos.
NOS (Network Operating System)
Sistema Operativo de Red. Sistema operativo que incluye funciones especiales para conectar computadoras y dispositivos en una red.
NTP (Network Time Protocol)
Protocolo de Tiempo de Red. Protocolo utilizado para sincronizar los relojes de los sistemas informáticos sobre redes con latencia variable.
NVMe (Non-Volatile Memory Express)
Express de Memoria No Volátil. Especificación de interfaz de comunicación para acceder a almacenamiento de estado sólido a través del bus PCI Express.
OCSP (Online Certificate Status Protocol)
Protocolo de Estado de Certificación en Línea. Protocolo utilizado para verificar el estado de revocación de un certificado digital en tiempo real.
OFDMA (Orthogonal Frequency Division Multiple Access)
Acceso Múltiple por División de Frecuencias Ortogonales. Técnica de acceso múltiple utilizada en tecnologías de comunicaciones inalámbricas como Wi-Fi 6 y 5G.
OSI (Open Systems Interconnection)
Interconexión de Sistemas Abiertos. Modelo de referencia de siete capas que describe cómo funciona la comunicación de red.
OSPF (Open Shortest Path First)
Abrir el Camino más Corto Primero. Protocolo de enrutamiento de estado-enlace utilizado dentro de sistemas autónomos.
OTDR (Optical Time Domain Reflectometer)
Reflectómetro de Dominio de Tiempo Óptico. Instrumento de prueba utilizado para caracterizar fibras ópticas y diagnosticar fallas.
PaaS (Platform as a Service)
Plataforma como Servicio. Modelo de computación en la nube que proporciona una plataforma completa para desarrollar, ejecutar y gestionar aplicaciones.
PAN (Personal Area Network)
Red de Área Personal. Red que conecta dispositivos de uso personal, típicamente dentro de un rango de pocos metros.
PAP (Password Authentication Protocol)
Protocolo de Autenticación de Contraseña. Protocolo de autenticación simple que verifica la identidad de un usuario mediante una combinación de nombre de usuario y contraseña.
PCAP (Packet Capture)
Captura de Paquetes. Técnica y formato de archivo para almacenar paquetes de datos capturados de una red.
PCIe (Peripheral Component Interconnect Express)
Interconexión de Componentes Periféricos Express. Estándar de bus de expansión de alta velocidad para conectar dispositivos periféricos a una computadora.
PDU (Protocol Data Unit)
Unidad de Datos del Protocolo. Formato en el que se transmiten los datos en cada capa del modelo OSI (bits, tramas, paquetes, segmentos).
PFS (Perfect Forward Secrecy)
Secreto Perfecto hacia Adelante. Propiedad de los sistemas de cifrado que asegura que las claves de sesión pasadas no puedan ser comprometidas si la clave maestra es comprometida posteriormente.
PGP (Pretty Good Privacy)
Privacidad Bastante Buena. Programa de cifrado que proporciona autenticación criptográfica y privacidad para la comunicación de datos.
PKI (Public Key Infrastructure)
Infraestructura de Clave Pública. Conjunto de políticas, hardware y software que permiten el intercambio seguro de información mediante certificados digitales.
PoE (Power over Ethernet)
Alimentación a través de Ethernet. Tecnología que permite que los cables de red Ethernet transmitan energía eléctrica junto con datos a dispositivos conectados.
POP3 (Post Office Protocol version 3)
Protocolo de Oficina de Correo versión 3. Protocolo de correo electrónico utilizado por clientes de correo para recuperar correos electrónicos de un servidor.
PPP (Point-to-Point Protocol)
Protocolo Punto a Punto. Protocolo de comunicación utilizado para establecer una conexión directa entre dos nodos.
PPPoE (Point-to-Point Protocol over Ethernet)
Protocolo Punto a Punto sobre Ethernet. Protocolo utilizado para encapsular tramas PPP dentro de tramas Ethernet.
PPTP (Point-to-Point Tunneling Protocol)
Protocolo de Túnel Punto a Punto. Protocolo de red obsoleto que permite la implementación de VPNs.
PRI (Primary Rate Interface)
Interfaz de Tasa Primaria. Interfaz de telecomunicaciones utilizada para servicios RDSI que proporciona múltiples canales B y un canal D.
PSTN (Public Switched Telephone Network)
Red Telefónica Pública Conmutada. Red telefónica tradicional que utiliza circuitos conmutados para conectar llamadas telefónicas.
QoS (Quality of Service)
Calidad de Servicio. Técnicas y mecanismos para priorizar el tráfico de red y garantizar niveles específicos de rendimiento.
RADIUS (Remote Authentication Dial-In User Service)
Servicio de Usuario de Discado de Autenticación Remota. Protocolo de red que proporciona autenticación, autorización y contabilidad centralizadas.
RAID (Redundant Array of Independent Disks)
Matriz Redundante de Discos Independientes. Tecnología de almacenamiento que combina múltiples discos físicos para mejorar el rendimiento o la redundancia.
RAM (Random Access Memory)
Memoria de Acceso Aleatorio. Memoria volátil utilizada por las computadoras para almacenar datos y código que están siendo utilizados activamente.
RDP (Remote Desktop Protocol)
Protocolo de Escritorio Remoto. Protocolo desarrollado por Microsoft que permite la conexión remota a otra computadora.
RF (Radio Frequency)
Radiofrecuencia. Rango de frecuencias de radiación electromagnética utilizado para comunicaciones inalámbricas.
RFI (Radio Frequency Interference)
Interferencia de Radiofrecuencia. Interferencia electromagnética que afecta las señales de radio y dispositivos electrónicos.
RIP (Routing Information Protocol)
Protocolo de Información de Enrutamiento. Protocolo de enrutamiento de distancia-vector utilizado en redes pequeñas y medianas.
RPO (Recovery Point Objective)
Objetivo de Punto de Recuperación. Métrica que define la cantidad máxima de datos que una organización puede permitirse perder en caso de un desastre.
RTP (Real-time Transport Protocol)
Protocolo de Transporte en Tiempo Real. Protocolo de red utilizado para entregar audio y video a través de redes IP.
RTT (Round Trip Time)
Tiempo de Ida y Vuelta. Tiempo que tarda un paquete en viajar desde un origen hasta un destino y volver.
SaaS (Software as a Service)
Software como Servicio. Modelo de distribución de software donde las aplicaciones son accedidas a través de Internet.
SAN (Storage Area Network)
Red de Área de Almacenamiento. Red especializada que proporciona acceso a almacenamiento de bloques de alto rendimiento.
SDN (Software-Defined Networking)
Redes Definidas por Software. Enfoque de gestión de redes que permite a los administradores gestionar servicios de red mediante abstracción de funciones de bajo nivel.
SDWAN (Software-Defined Wide Area Network)
Red de Área Amplia Definida por Software. Aplicación de tecnología SDN a las redes WAN empresariales.
SFP (Small Form-Factor Pluggable)
Enchufable de Factor de Forma Pequeño. Transceptor modular caliente utilizado para interconectar equipos de red.
SFTP (SSH File Transfer Protocol)
Protocolo de Transferencia de Archivos SSH. Protocolo de transferencia de archivos que utiliza el protocolo SSH para seguridad.
SIMM (Single In-Line Memory Module)
Módulo de Memoria en Línea Simple. Tipo de módulo de memoria RAM utilizado en computadoras antiguas.
SLA (Service Level Agreement)
Acuerdo de Nivel de Servicio. Contrato que define el nivel esperado de servicio entre un proveedor y un cliente.
SMB (Server Message Block)
Bloque de Mensajes del Servidor. Protocolo de compartilhamiento de archivos, impresoras y puertos serie en una red.
SMS (Short Message Service)
Servicio de Mensajes Cortos. Servicio de mensajería texto que permite enviar mensajes de hasta 160 caracteres entre teléfonos móviles.
SMTP (Simple Mail Transfer Protocol)
Protocolo Simple de Transferencia de Correo. Protocolo de la capa de aplicación utilizado para enviar correos electrónicos entre servidores.
SNMP (Simple Network Management Protocol)
Protocolo Simple de Gestión de Red. Protocolo utilizado para la gestión y monitoreo de dispositivos de red.
SOHO (Small Office/Home Office)
Pequeña Oficina/Oficina en Casa. Término que se refiere a pequeñas empresas o entornos de trabajo doméstico.
SONET (Synchronous Optical Networking)
Red óptica síncrona. Estándar de transmisión de datos sobre fibra óptica que define velocidades de transmisión síncronas.
SPF (Sender Policy Framework)
Marco de Política del Remitente. Técnica de autenticación de correo electrónico que verifica que el correo proviene de un servidor autorizado.
SPOF (Single Point of Failure)
Punto Único de Fallo. Componente de un sistema que, si falla, causa que todo el sistema deixe de funcionar.
SSH (Secure Shell)
Capa de Shell Segura. Protocolo de red que permite acceso remoto seguro a sistemas informáticos mediante cifrado.
SSID (Service Set Identifier)
Identificador de Conjunto de Servicios. Nombre que identifica una red inalámbrica (Wi-Fi).
SSL (Secure Sockets Layer)
Capa de Zócalos Seguros. Protocolo de seguridad que proporciona comunicaciones cifradas entre un servidor web y un navegador.
STP (Spanning Tree Protocol)
Protocolo de Árbol de Expansión. Protocolo de capa 2 que previene bucles en topologías de red conmutada.
TACACS+ (Terminal Access Controller Access-Control System Plus)
Sistema de Control de Acceso del Controlador de Acceso Terminal Plus. Protocolo de autenticación remoto utilizado para controlar el acceso a dispositivos de red.
TCP (Transmission Control Protocol)
Protocolo de Control de Transmisión. Protocolo de la capa de transporte orientado a conexión que garantiza la entrega ordenada de datos.
TDM (Time Division Multiplexing)
Multiplexación por División de Tiempo. Técnica de multiplexación donde múltiples señales comparten el mismo canal de comunicación.
TDR (Time Domain Reflectometer)
Reflectómetro de Dominio de Tiempo. Instrumento de prueba utilizado para caracterizar cables eléctricos y diagnosticar fallas.
TKIP (Temporal Key Integrity Protocol)
Protocolo de Integridad de Clave Temporal. Protocolo de seguridad desarrollado para corregir vulnerabilidades en WEP.
TLS (Transport Layer Security)
Seguridad de la Capa de Transporte. Protocolo de seguridad que proporciona cifrado y autenticación para comunicaciones de red.
UCS (Unified Computing System)
Sistema de Computación Unificada. Plataforma de centro de datos virtualizada de Cisco que integra computación, red y almacenamiento.
UDP (User Datagram Protocol)
Protocolo de Datagramas de Usuario. Protocolo de la capa de transporte sin conexión que proporciona entrega rápida pero no garantizada de datos.
UEFI (Unified Extensible Firmware Interface)
Interfaz de Firmware Extensible Unificada. Especificación de firmware que reemplaza al BIOS tradicional en computadoras modernas.
UPS (Uninterruptible Power Supply)
Fuente de Alimentación Ininterrumpida. Dispositivo que proporciona energía de respaldo cuando la alimentación principal falla.
URL (Uniform Resource Locator)
Localizador Uniforme de Recursos. Dirección web que especifica la ubicación de un recurso en Internet.
USB (Universal Serial Bus)
Bus Serie Universal. Estándar de conexión utilizado para conectar periféricos a una computadora.
UTP (Unshielded Twisted Pair)
Par Trenzado No Blindado. Tipo de cable de red que consiste en pares de cables trenzados sin blindaje metálico.
VLAN (Virtual Local Area Network)
Red de Área Local Virtual. Técnica que permite crear múltiples redes lógicas dentro de una misma infraestructura física.
VM (Virtual Machine)
Máquina Virtual. Emulación de un sistema informáticos que ejecuta programas como si fuera una computadora física.
VoIP (Voice over IP)
Voz sobre IP. Tecnología que permite la transmisión de voz sobre redes IP, como Internet.
VPN (Virtual Private Network)
Red Privada Virtual. Red segura que utiliza infraestructura pública para conectar usuarios remotos de manera cifrada.
VRF (Virtual Routing and Forwarding)
Enrutamiento y Reenvío Virtual. Tecnología que permite múltiples instancias de tablas de enrutamiento funcionar simultáneamente en un mismo router.
VRRP (Virtual Router Redundancy Protocol)
Protocolo de Redundancia de Router Virtual. Protocolo que proporciona redundancia de puerta de enlace predeterminada.
VTP (VLAN Trunking Protocol)
Protocolo de Troncalización VLAN. Protocolo de Cisco utilizado para propagar información de VLANs a través de switches en una red.
WAP (Wireless Access Point)
Punto de Acceso Inalámbrico. Dispositivo que permite a dispositivos inalámbricos conectarse a una red cableada.
WEP (Wired Equivalent Privacy)
Privacidad Equivalente al Cableado. Estándar de seguridad obsoleto para redes inalámbricas.
WIFI (Wireless Fidelity)
Fidelidad Inalámbrica. Término comercial para IEEE 802.11, tecnologías de redes inalámbricas.
WINS (Windows Internet Name Service)
Servicio de Nombres de Internet de Windows. Sistema de nombres que traduce nombres NetBIOS a direcciones IP.
WLAN (Wireless Local Area Network)
Red de Área Local Inalámbrica. Red local que utiliza tecnologías de comunicación inalámbrica.
WPA (Wi-Fi Protected Access)
Acceso Protegido Wi-Fi. Estándar de seguridad para redes inalámbricas que corrige las vulnerabilidades de WEP.
WPA2 (Wi-Fi Protected Access 2)
Acceso Protegido Wi-Fi 2. Versión mejorada de WPA que utiliza el algoritmo de cifrado AES-CCMP.
WPA3 (Wi-Fi Protected Access 3)
Acceso Protegido Wi-Fi 3. La última versión del estándar de seguridad Wi-Fi, introducida en 2018.
XOR (Exclusive OR)
O Exclusivo. Operación lógica que devuelve verdadero solo cuando las entradas son diferentes.
ZFS (Zettabyte File System)
Sistema de Archivos Zettabyte. Sistema de archivos avanzado que combina conceptos de sistema de archivos y administrador de volúmenes lógicos.

Glosario de Términos

Ancho de Banda
Capacidad máxima de transmisión de datos de un canal de comunicación, generalmente medida en bits por segundo (bps). Representa la cantidad de información que puede transferirse en un período de tiempo determinado.
Archivo de Configuración
Documento o conjunto de documentos que contienen los parámetros y ajustes necesarios para que un dispositivo o sistema funcione correctamente en una red específica.
Balanceo de Carga
Técnica utilizada para distribuir el tráfico de red entre múltiples servidores o rutas para optimizar el uso de recursos y maximizar el rendimiento.
Bastidor
Estructura metálica utilizada para organizar y montar equipos de red, servidores y otros dispositivos informáticos en centros de datos.
Bit
Unidad básica de información en computación y comunicaciones digitales. Un bit puede tener un valor de 0 o 1.
Bloqueo de Puertos
Medida de seguridad que restringe el acceso a puertos específicos de un dispositivo o red, previniendo comunicaciones no autorizadas.
Byte
Unidad de información digital compuesta típicamente por 8 bits. Representa un carácter en la mayoría de los sistemas de codificación.
Cable de Cobre
Medio de transmisión físico compuesto por hilos de cobre, utilizado ampliamente en telecomunicaciones y redes de datos. Incluye categorías como UTP, STP y coaxial.
Cable de Fibra Óptica
Medio de transmisión que utiliza fibras de vidrio o plástico para transmitir datos como pulsos de luz. Ofrece alta capacidad de ancho de banda y baja atenuación.
Cabling
Infraestructura física de cables que conecta dispositivos de red. Incluye cables de cobre, fibra óptica y los componentes asociados como conectores y paneles de parcheo.
Centro de Datos
Instalación dedicada que contiene sistemas informáticos y componentes asociados, incluyendo sistemas de almacenamiento, redes y ambientales.
Circuito
Trayectoria completa para el flujo de corriente eléctrica o señales de datos. En redes, puede referirse a una conexión dedicada entre dos puntos.
Concentrador (Hub)
Dispositivo de red que conecta múltiples dispositivos Ethernet y retransmite los datos recibidos a todos los puertos conectados.
Conmutador (Switch)
Dispositivo de red que opera en la capa 2 del modelo OSI y utiliza direcciones MAC para dirigir el tráfico solo al puerto de destino apropiado.
Conexión Cruzada
Conexión entre dos dispositivos o sistemas que permite la transferencia de datos. En telecomunicaciones, puede referirse a la interconexión física entre equipos.
Conjunto de Enlace
Grupo de interfaces de red que funcionan como una única interfaz lógica para aumentar el ancho de banda o proporcionar redundancia.
Continuidad
Características de un cable o circuito que permite el flujo ininterrumpido de señales eléctricas u ópticas desde un punto hasta otro.
Cortafuegos (Firewall)
Sistema de seguridad de red que monitorea y controla el tráfico de red entrante y saliente basándose en reglas de seguridad predeterminadas.
Costo
Valor numérico asignado a una ruta de red que indica su desirabilidad relativa. Los protocolos de enrutamiento utilizan el costo para seleccionar la mejor ruta.
CRC (Comprobación de Redundancia Cíclica)
Técnica de detección de errores que verifica la integridad de los datos transmitidos calculando una suma de verificación basada en el contenido de los datos.
Datagrama
Unidad de transferencia de datos autónoma que puede ser enrutada independientemente. El término se usa comúnmente en referencia a los paquetes UDP.
Demanda
En el contexto de redes, se refiere a la cantidad de recursos de red requeridos por los usuarios o aplicaciones en un momento dado.
Desviación
En el cableado estructurado, se refiere a la desviación del cable respecto a su trayectoria ideal. En electrónica, puede referirse a diferencias en señales o tiempos.
Diagrama de Red
Representación visual de la infraestructura de red, mostrando dispositivos, conexiones, topología y flujos de datos.
Direccionamiento
Proceso de asignar direcciones únicas a dispositivos en una red para permitir su identificación y comunicación.
Dirección IP
Identificador numérico único asignado a cada dispositivo conectado a una red que utiliza el protocolo IP para comunicación.
Dispositivo de Red
Hardware que permite la comunicación y transferencia de datos entre dispositivos en una red. Incluye routers, switches, firewalls, puntos de acceso y otros.
Dominio
Grupo de dispositivos y recursos de red administrados como una unidad. También se refiere a un nombre de dominio en Internet.
Dominio de Colisión
Segmento de red donde los paquetes pueden colisionar entre sí cuando se transmiten simultáneamente. Los switches segmentan los dominios de colisión.
Dominio de Difusión
Segmento de red donde un paquete de difusión enviado por cualquier dispositivo será recibido por todos los demás dispositivos del segmento. Los routers segmentan los dominios de difusión.
Duplex
Modo de comunicación que permite la transmisión simultánea de datos en ambas direcciones. Puede ser half-duplex (alternada) o full-duplex (simultánea).
Encriptación
Proceso de convertir información legible (texto plano) en un formato codificado (texto cifrado) para prevenir el acceso no autorizado.
Enlace
Conexión física o lógica entre dos dispositivos o redes. Puede referirse a un cable individual, un circuito o una conexión inalámbrica.
Enrutamiento
Proceso de seleccionar la trayectoria que tomarán los paquetes de datos a través de una red para alcanzar su destino.
Enrutamiento Dinámico
Método de enrutamiento donde los protocolos de enrutamiento actualizan automáticamente las tablas de enrutamiento en respuesta a cambios en la red.
Enrutamiento Estático
Método de enrutamiento donde las rutas se configuran manualmente y no cambian automáticamente en respuesta a cambios en la red.
Escalabilidad
Capacidad de un sistema, red o proceso para manejar crecientes cantidades de trabajo o para ampliarse para acomodar crecimiento futuro.
Espejo de Puerto
Función en switches que permite copiar el tráfico de uno o más puertos a otro puerto para análisis y monitoreo.
Estandarización
Proceso de desarrollar e implementar estándares técnicos que aseguran la interoperabilidad y compatibilidad entre dispositivos y sistemas.
Estándar
Especificación técnica formal que define requisitos, protocolos o procedimientos para productos o servicios específicos.
Ethernet
Tecnología de red cableada ampliamente utilizada para redes locales (LAN) que define los estándares de cableado y señalización.
Explotación de vulnerabilidades
Acción de aprovechar debilidades o fallos en sistemas informáticos para obtener acceso no autorizado o realizar acciones no previstas.
Falla
Condición en la que un componente, sistema o red no funciona correctamente, generalmente resultando en pérdida de servicio o funcionalidad degradada.
Filtro de Direcciones MAC
Técnica de seguridad que permite o bloquea dispositivos basándose en sus direcciones MAC únicas.
Firma Digital
Mecanismo criptográfico que verifica la autenticidad e integridad de un mensaje o documento digital.
Frecuencia
Número de ciclos de una señal periódica por unidad de tiempo, generalmente medida en Hertz (Hz). En redes inalámbricas, determina el canal de transmisión.
Fuera de Banda
Método de administración que utiliza un canal de comunicación separado de la red principal para acceder y gestionar dispositivos.
Gateway
Dispositivo o sistema que conecta redes con diferentes protocolos o arquitecturas, traduciéndolos para permitir la comunicación.
Gestión de Redes
Conjunto de actividades y herramientas utilizadas para operar, administrar y mantener una infraestructura de red.
Grifo
Dispositivo de monitoreo que permite observar el tráfico de red sin interrumpir el flujo normal de datos.
Hash
Función criptográfica que convierte datos de cualquier tamaño en una cadena de caracteres de longitud fija, utilizada para verificar integridad.
Hop (Salto)
Movimiento de un paquete de datos de un router o dispositivo de red al siguiente en su trayectoria hacia el destino.
Hostname
Etiqueta asignada a un dispositivo en una red que lo identifica de manera única dentro de un dominio de red.
IEEE
Instituto de Ingenieros Eléctricos y Electrónicos. Organización que desarrolla estándares técnicos, incluyendo los estándares de redes 802.x.
Indicadores de Rendimiento
Métricas utilizadas para evaluar el funcionamiento y eficiencia de una red, como latencia, throughput y pérdida de paquetes.
Infraestructura de Red
Conjunto de componentes físicos y lógicos que permiten la conectividad y comunicación en una red de datos.
Integridad
Garantía de que los datos no han sido alterados o modificados de manera no autorizada durante la transmisión o almacenamiento.
Interfaz
Punto de conexión entre dos sistemas o dispositivos. Puede ser física (un puerto) o lógica (una configuración de software).
IPsec
Suite de protocolos que proporciona seguridad a nivel de IP mediante autenticación y cifrado de cada paquete IP.
Jitter
Variación en el tiempo de llegada de paquetes consecutivos. Afecta negativamente la calidad de aplicaciones en tiempo real como VoIP y video.
Latencia
Tiempo que tarda un paquete de datos en viajar desde el origen hasta el destino. Factor crítico en el rendimiento de la red.
Línea de Suscriptor
Circuito de telecomunicaciones que conecta el equipo del usuario final (CPE) a la central de conmutación del proveedor de servicios.
Localhost
Dirección IP especial (127.0.0.1) que hace referencia a la computadora local o dispositivo en uso.
Mecanismo de Reserva
Procedimiento o sistema alternativo que se activa cuando el sistema principal falla, asegurando la continuidad del servicio.
Medio de Transmisión
Canal físico o inalámbrico a través del cual se transmiten señales de datos. Incluye cobre, fibra óptica y espectro de radio.
Mesh (Malla)
Topología de red donde los dispositivos están conectados entre sí, permitiendo múltiples rutas de comunicación.
Métrica
Valor numérico utilizado para evaluar el rendimiento o estado de un componente de red. Los protocolos de enrutamiento usan métricas para determinar la mejor ruta.
Modulación
Proceso de variar una señal portadora (amplitud, frecuencia o fase) para transmitir información.
Multidifusión (Multicast)
Método de comunicación donde un emisor envía datos a un grupo específico de receptores simultáneamente.
Nivel de Potencia
Medida de la intensidad de una señal de transmisión, generalmente expresada en decibelios (dBm o dB).
Nube
Infraestructura de computación que proporciona recursos compartidos, aplicaciones y servicios a través de Internet.
Octeto
Grupo de 8 bits. Las direcciones IPv4 se representan como cuatro octetos separados por puntos (por ejemplo, 192.168.1.1).
Onda Portadora
Señal electromagnética de frecuencia constante que se modifica para transportar información en comunicaciones.
Parche
Actualización de software que corrige errores, vulnerabilidades o añade funcionalidad. También se refiere a los cables de conexión cortos.
Paquete
Unidad de datos transmitida a través de una red. Incluye la carga útil (datos) y encabezado con información de direccionamiento.
Pérdida de Inserción
Atenuación de señal causada por la introducción de componentes como conectores, empalmes o adaptadores en un cable.
Ping
Utilidad de red que envía mensajes ICMP Echo Request a un host de destino para verificar su accesibilidad y medir la latencia.
Pirámide de Jerarquía
Estructura organizativa de red que separa los dispositivos en capas: acceso, distribución y núcleo para optimizar el rendimiento y la gestión.
Plano de Control
Componente de un dispositivo de red responsable de las funciones de enrutamiento y decisiones sobre dónde enviar el tráfico.
Plano de Datos
Componente de un dispositivo de red responsable del reenvío real del tráfico basándose en la información del plano de control.
PoE (Alimentación sobre Ethernet)
Tecnología que permite transmitir energía eléctrica junto con datos a través de cables Ethernet a dispositivos como cámaras IP y puntos de acceso.
Políticas de Seguridad
Conjunto de reglas y procedimientos diseñados para proteger la información y los recursos de una organización contra accesos no autorizados.
Portadora
Señal de frecuencia específica utilizada para transportar información modulada en comunicaciones de radio o telecomunicaciones.
Prefijo
Parte de una dirección IP que identifica la red. En CIDR, se representa como /n donde n es el número de bits del prefijo.
Priorización
Técnica de QoS que asigna niveles de importancia al tráfico de red para garantizar que el tráfico crítico reciba recursos preferentes.
Protocolo
Conjunto de reglas y convenciones que determinan cómo se formatean, transmiten y reciben los datos en una red.
Protocolo de Conmutación
Protocolo utilizado para determinar qué puertos deben bloquearse y cuáles deben habilitarse para evitar bucles en topologías de red conmutada.
Puente (Bridge)
Dispositivo de red que conecta múltiples segmentos de red en la capa 2, utilizando direcciones MAC para filtrar el tráfico.
Puerto
Punto de conexión física en un dispositivo de red. También se refiere a puntos lógicos identificados por números (0-65535) que distinguen diferentes servicios o conexiones.
Puertos de Red
Interfaces físicas en switches, routers u otros dispositivos de red donde se conectan cables para establecer comunicaciones.
Quedada
Conexión permanente o temporal establecida entre dispositivos de red para comunicación o pruebas.
Red de Computadoras
Sistema de dispositivos interconectados que pueden comunicarse y compartir recursos e información.
Redundancia
Duplicación de componentes críticos o rutas de comunicación para proporcionar fiabilidad y disponibilidad en caso de fallos.
Regenerador
Dispositivo que amplifica y regenera señales de datos que se han debilitado durante la transmisión a larga distancia.
Reintentos
Número de veces que un dispositivo intentará retransmitir datos cuando no se recibe confirmación de entrega.
Remitente
Dispositivo o sistema que origina y transmite datos a través de una red hacia un destino específico.
Réplica
Copia de datos o sistemas almacenada en múltiples ubicaciones para mejorar la disponibilidad y tolerancia a fallos.
Respaldo
Copia de seguridad de datos o configuraciones almacenada separadamente para permitir la recuperación en caso de pérdida o daño.
Retardo
Tiempo adicional introducido en la transmisión de datos debido a procesamiento, encolamiento o distancia.
Revisión de Puertos
Proceso de verificación y análisis de los puertos abiertos en un dispositivo para identificar servicios activos y potenciales vulnerabilidades.
Rollo de Cable
Cantidad continua de cable enrollada, típicamente medida en pies o metros, utilizada para instalaciones de cableado de red.
Rollo de Cables
Cantidad continua de cable de red enrollada en un carrete, utilizada para instalaciones de infraestructura de telecomunicaciones.
Ruta
Trayectoria específica que siguen los paquetes de datos desde un origen hasta un destino a través de una red.
Rutas Estáticas
Rutas de red configuradas manualmente en un router que no cambian automáticamente según las condiciones de la red.
Sectorización Celular
Técnica utilizada en redes móviles para dividir una célula de cobertura en múltiples sectores para aumentar la capacidad.
Segmentación
División de una red en segmentos más pequeños para mejorar el rendimiento, seguridad y gestión.
Seguridad de Red
Prácticas y tecnologías diseñadas para proteger la integridad, confidencialidad y disponibilidad de los recursos de red.
Servidor
Computadora o sistema que proporciona recursos, datos, servicios o programas a otros dispositivos (clientes) en una red.
Sistema de Detección de Intrusiones (IDS)
Sistema que monitorea el tráfico de red en busca de actividades maliciosas y genera alertas cuando detecta amenazas potenciales.
Sistema de Nombres de Dominio (DNS)
Sistema que traduce nombres de dominio legibles por humanos a direcciones IP numéricas utilizadas por las computadoras.
Sobrecarga de IP
Técnica de traducción de direcciones que permite compartir una única dirección IP pública entre múltiples hosts con direcciones privadas.
Sondeo
Técnica de monitoreo que envía consultas o señales a dispositivos de red para verificar su estado y disponibilidad.
Splitter
Dispositivo que divide una señal en múltiples señales o combina múltiples señales en una sola.
Subnetting
Proceso de subdividir una red IP en subredes más pequeñas para mejorar la eficiencia y seguridad del direccionamiento.
Tabla ARP
Estructura de datos que mapea direcciones IP a direcciones MAC correspondientes en una red local.
Tabla de Enrutamiento
Estructura de datos almacenada en un router que contiene información sobre las rutas disponibles hacia diferentes destinos.
Tasa de Bits
Número de bits transmitidos por unidad de tiempo, generalmente expresado en bits por segundo (bps) o sus múltiplos (Kbps, Mbps, Gbps).
Tendido de Cable
Proceso de instalación física de cables de red a través de conduit, canaletas o directamente en paredes y suelos.
Tierra Física
Conexión eléctrica directa a tierra que proporciona un camino de baja resistencia para corrientes de falla y protección contra sobrevoltajes.
Token
Paquete especial que circula en redes Token Ring, otorga el derecho de transmitir a la estación que lo posee.
Topología
Disposición física o lógica de dispositivos y conexiones en una red. Incluye topologías como estrella, anillo, bus y malla.
Trunking
Técnica que permite que múltiples VLANs utilicen un mismo enlace físico para transportar tráfico de varias VLANs simultáneamente.
Tunneling (Túnel)
Técnica que encapsula un protocolo dentro de otro para permitir que atraviese redes que normalmente no lo soportarían.
Unicast
Método de comunicación donde los datos se envían desde un origen a un único destino específico.
VLAN (Red de Área Local Virtual)
Técnica que permite crear múltiples redes lógicas aisladas dentro de una misma infraestructura física de switch.
Vulnerabilidad
Debilidad en un sistema, proceso o configuración que puede ser explotada para comprometer la seguridad.
WAN
Red de Área Amplia. Red que conecta dispositivos a través de grandes distancias geográficas, a diferencia de las redes LAN.
Zona Desmilitarizada (DMZ)
Subred que separa la red interna de una organización de redes externas no confiables como Internet, conteniendo servicios expuestos públicamente.
