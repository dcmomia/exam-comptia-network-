Capítulo 22: Herramientas del Oficio: Hardware y Software

Introducción: El Kit Esencial del Administrador

Un buen mecánico no arregla un motor con las manos vacías; necesita llaves y destornilladores. Un administrador de red necesita su propio kit de herramientas.

Para el examen N10-009, debes saber exactamente qué herramienta usar para cada situación. Usar un multímetro para probar un problema de DNS es tan inútil como usar un martillo para cortar papel.

Estos comandos deben estar grabados en tu memoria muscular. El examen no solo te preguntará qué hace el comando, sino qué bandera (flag) específica necesitas para una tarea concreta.

Análisis de Conexiones: Netstat

El comando netstat es vital para la seguridad del host. Permite auditar qué conexiones están establecidas y qué puertos están "escuchando".

Bandera Función Importancia para el Examen
-a All: Muestra todas las conexiones y puertos de escucha. Para ver qué puertos están abiertos.
-n Numerical: Muestra IPs y puertos numéricos (no resuelve nombres). Mucho más rápido que el estándar.
-o Owner: Muestra el PID (Process ID) dueño de la conexión. Crítico para detectar malware.

🛡️ Escenario de Seguridad: Detectando Malware con Netstat

Problema: El ordenador va lento y sospechas que un malware está enviando datos, pero no tienes un antivirus a mano.

Solución Manual:

  1. Ejecuta netstat -ano. Busca conexiones en estado ESTABLISHED hacia IPs extrañas.
  2. Identifica el PID (ej. 4022) asociado a esa conexión sospechosa.
  3. Ejecuta tasklist (en Windows) o ps (en Linux) para ver qué nombre de programa corresponde al PID 4022.
  4. Si el nombre es sospechoso (ej. juego_crack.exe), finaliza el proceso (taskkill o kill).

Escaneo y Análisis Avanzado (Nmap y Sniffers)

Estas herramientas se utilizan para auditoría de seguridad y diagnósticos profundos.

Nmap (Network Mapper) - Banderas Esenciales

Bandera Nombre Técnico Descripción
-sn Ping Scan Solo descubre qué hosts están vivos (sin escanear puertos).
-sS SYN Scan (Stealth) El más usado. Envía un paquete SYN y no completa la conexión (evita logs simples). Requiere permisos de root/admin.
-O OS Detection Intenta adivinar el Sistema Operativo del objetivo (ej. "Linux Kernel 4.0").
-p Port Specification Escanea puertos específicos (ej. -p 80,443).

Captura de Paquetes (Packet Sniffing)

  • Wireshark: Herramienta gráfica para análisis profundo. Ideal para ver el contenido del paquete (si no está cifrado) y diagnosticar problemas de aplicación.
  • Tcpdump: Herramienta de línea de comandos (Linux). Ideal para servidores sin interfaz gráfica.
    • tcpdump -i eth0: Escuchar en la interfaz eth0.
    • tcpdump -w captura.pcap: Write. Guarda el tráfico en un archivo para analizarlo luego en Wireshark.

Herramientas de Hardware: El Maletín Físico

Cuando el problema es físico (Capa 1), el software no te ayudará. Debes elegir la herramienta correcta según el medio (cobre o fibra).

Diagnóstico de Cobre

Herramienta Función Principal Palabra Clave en Examen
Probador de Cables (Cable Tester) Verifica continuidad básica (mapa de cableado). "Open", "Short", "Crossed pair", "Wiremap".
TDR (Time Domain Reflectometer) Localiza la distancia exacta hasta una rotura en el cable. "Metros hasta el fallo", "Cable cortado en la pared".
Certificador Valida la velocidad y categoría (Cat 5e/6/6a). Mide diafonía y atenuación. "Validar ancho de banda", "Informe de certificación".
Generador de Tonos (Fox and Hound) Localiza un cable físico en un mazo desordenado mediante sonido. "Sonda", "Cable perdido", "Sin etiqueta".

Diagnóstico de Fibra Óptica

⚠️ Diferencia Crítica: No confundas el OTDR con el Medidor de Luz.
  • OTDR (Optical TDR): Te dice dónde está el fallo (distancia). Encuentra roturas o empalmes malos.
  • Medidor de Luz (Optical Power Meter): Te dice cuánta señal se pierde (dB). Mide la atenuación total del enlace.

Otras Herramientas Esenciales

  • Loopback Plug: Un conector "falso" que devuelve la señal a la tarjeta de red. Sirve para probar si el puerto físico (NIC) está dañado cuando el sistema operativo dice "Cable desconectado" pero el cable está bien.
  • Analizador de Espectro Wi-Fi: Detecta interferencias no-WiFi (microondas, bluetooth) y mide la relación Señal/Ruido (SNR).
  • Empalmadora de Fusión (Fusion Splicer): Une permanentemente dos hilos de fibra rota fundiendo el vidrio. Es la reparación de mayor calidad para cortes de fibra.

📌 Resumen de Puntos Clave

  • Ping: Conectividad básica.
  • Tracert: Identificar el router donde se corta el tráfico.
  • Ipconfig: Verificar IP, Gateway y detectar APIPA.
  • Nslookup/Dig: Problemas de resolución de nombres (DNS).
  • Netstat -ano: Detectar conexiones sospechosas y malware.
  • Nmap: Inventario de red y auditoría de puertos abiertos.
  • TDR/OTDR: Encontrar la ubicación física (distancia) de una rotura.
