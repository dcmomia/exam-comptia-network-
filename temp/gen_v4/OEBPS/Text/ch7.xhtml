Pregunta 14: Bethany, una administradora de red, quiere asegurar que las direcciones IP no queden reservadas indefinidamente por dispositivos que ya no están activos en la red. ¿Qué característica de DHCP permitiría a un administrador controlar el periodo que un dispositivo puede usar una dirección IP asignada?

  • Exclusiones
  • Tiempo de Distribución (Lease Time)
  • Opciones
  • Ámbito (Scope)

Respuesta: Tiempo de Distribución (Lease Time)

Explicación: El Lease Time o Tiempo de Concesión define cuánto tiempo un cliente puede usar una dirección IP antes de tener que renovarla o devolverla al pool.
