Capítulo 1: El Modelo OSI

Pregunta 74: ¿Qué capa del modelo OSI interactúa con el software del usuario final, como por ejemplo al usar un navegador web para comunicarse a través de HTTP para mostrar un sitio web?

  • Capa 5
  • Capa 4
  • Capa 6
  • Capa 7

Respuesta: Capa 7

Explicación: La capa 7 (Capa de Aplicación) es la capa del modelo OSI más cercana al usuario final. Proporciona servicios de red a las aplicaciones de software (como navegadores web o clientes de correo) y protocolos como HTTP, FTP y SMTP operan en esta capa.
