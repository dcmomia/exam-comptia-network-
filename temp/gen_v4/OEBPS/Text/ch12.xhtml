Pregunta 9: ¿Cuál de las siguientes infraestructuras de nube incluye servidores locales que utilizan un servidor Syslog centralizado alojado en una organización de terceros para revisar los registros?

  • Comunitaria (Community)
  • Privada (Private)
  • Híbrida (Hybrid)
  • Pública (Public)

Respuesta: Híbrida (Hybrid)

Explicación: Una nube híbrida combina infraestructura propia (on-premise) con servicios de terceros o nubes públicas/comunitarias. En este escenario, la conexión entre el servidor local y el servicio externo de Syslog define un modelo híbrido.

Referencia: Capítulo 8: Tecnologías de Nube y Virtualización > Modelos de Despliegue de Nube

Pregunta 15: En entornos de nube, ¿qué opción está diseñada específicamente para permitir el acceso a Internet para los recursos dentro de una VPC sin exponerlos directamente a Internet?

  • NAT Gateway
  • Direct Connect Gateway
  • Internet Gateway
  • VPN Gateway

Respuesta: NAT Gateway

Explicación: Una NAT Gateway permite que instancias en una subred privada se conecten a Internet (para actualizaciones, etc.) pero evita que Internet inicie conexiones directas con esas instancias.

Pregunta 51: En el contexto de VXLAN (Virtual Extensible Local Area Network), ¿cuál es el propósito del Identificador de Red VXLAN (VNI)?

  • Se utiliza para diferenciar entre diferentes redes superpuestas (overlay) de VXLAN.
  • Se utiliza para autenticar los paquetes VXLAN para asegurar la seguridad.
  • Se utiliza para designar las direcciones IP de origen y destino para el tráfico VXLAN.
  • Se utiliza para identificar de forma única cada punto final del túnel VXLAN (VTEP).

Respuesta: Se utiliza para diferenciar entre diferentes redes superpuestas (overlay) de VXLAN.

Explicación: El VNI (VXLAN Network Identifier) es un identificador de 24 bits (que permite hasta 16 millones de redes) utilizado para segmentar y distinguir diferentes redes virtuales de capa 2 que se transportan sobre una red de capa 3 (overlay).

Referencia: Capítulo 8: Tecnologías de Nube y Virtualización > Segmentación con VXLAN

Pregunta 83: Dion Training Solutions quiere migrar su servidor de correo electrónico de una solución local (on-premise) a una solución basada en la web alojada por un proveedor, como Google Workspace o Gmail. ¿Cuál de los siguientes tipos de modelos de nube describe mejor esta solución propuesta?

  • PaaS
  • SaaS
  • DaaS
  • IaaS

Respuesta: SaaS

Explicación: Google Workspace y Gmail son ejemplos clásicos de Software como Servicio (SaaS), donde el usuario accede a una aplicación completa a través de la web sin preocuparse por la infraestructura, el sistema operativo o el mantenimiento del software subyacente.

Referencia: Capítulo 8: Tecnologías de Nube y Virtualización > Modelos de Servicio
