Pregunta 59: Dion Training quiere crear un registro DNS para introducir información DKIM o SPF en el sistema de nombres de dominio y ayudar a prevenir el spam que sale de su dominio. ¿Qué tipo de registro DNS debería crearse?

  • SRV
  • SOA
  • PTR
  • TXT

Respuesta: TXT

Explicación: Los registros TXT (Text) se utilizan para almacenar información de texto legible por máquina. Protocolos de seguridad de correo electrónico como SPF (Sender Policy Framework) y DKIM (DomainKeys Identified Mail) utilizan registros TXT para publicar las listas de servidores autorizados y las claves criptográficas para la verificación.

Referencia: Capítulo 5: Servicios y Protocolos de Aplicación IP > Registros de Recursos DNS

Pregunta 61: ¿Qué puerto se usa comúnmente para recibir correos electrónicos desde un servidor de correo?

  • Puerto 25
  • Puerto 110
  • Puerto 80
  • Puerto 443

Respuesta: Puerto 110

Explicación: El protocolo POP3 (Post Office Protocol version 3) utiliza el puerto 110 por defecto para permitir que los clientes de correo descarguen mensajes desde un servidor. El puerto 25 es para SMTP (envío), el 80 para HTTP y el 443 para HTTPS.

Referencia: Capítulo 5: Servicios y Protocolos de Aplicación IP > Puertos de Protocolo de Correo

Pregunta 71: ¿Qué protocolo se utiliza para la sincronización de relojes entre diferentes sistemas informáticos a través de una red de datos conmutada por paquetes y latencia variable?

  • NTP
  • DHCP
  • DNS
  • TFTP

Respuesta: NTP

Explicación: NTP (Network Time Protocol) está diseñado específicamente para sincronizar los relojes de los dispositivos de red con una referencia de tiempo precisa (como un reloj atómico) a través de redes con latencia variable, asegurando que todos los logs y transacciones tengan marcas de tiempo consistentes.

Referencia: Capítulo 5: Servicios y Protocolos de Aplicación IP > NTP

Pregunta 77: ¿Qué combinación(es) de puerto y protocolo se asocian comúnmente con el Protocolo de Escritorio Remoto (RDP)?

  • Puerto 5060/5061 - UDP
  • Puerto 5060/5061 - TCP
  • Puerto 3389 - TCP
  • Puerto 3389 - UDP

Respuesta: Puerto 3389 - TCP

Explicación: RDP utiliza por defecto el puerto 3389 sobre el protocolo de transporte TCP. Aunque las versiones modernas pueden utilizar UDP para optimizar la transmisión de gráficos y multimedia, TCP sigue siendo el estándar fundamental de conexión para RDP.
