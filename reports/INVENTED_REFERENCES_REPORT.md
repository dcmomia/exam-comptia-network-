# REPORT: Invented References Audit
**Date**: 2026-02-02
**Source**: `CompTIA_Network_Final.epub`

## Executive Summary

The audit script compared 181 question references against the actual Table of Contents of the EPUB. While previous efforts corrected chapter titles and numbers, a significant number of **sections** are still "invented" or hallucinated (meaning they don't exist in the book with those names).

| Metric | Results |
| :--- | :--- |
| **Total Questions Audited** | 181 |
| **Questions with Valid References** | ~50% (estimated) |
| **Questions with Invented Sections** | ~45% |

## Root Cause Analysis
The references were likely generated by an AI model that had a "good idea" of the content but didn't have the exact Table of Contents during the generation process, leading to **semantically correct but structurally incorrect** references.

## Recommended Next Steps
1.  **Standardization**: Update `reference_mapping.json` to include these section-level corrections.
2.  **Automated Patch**: Run a script to replace the "invented" strings with the "actual" strings from the EPUB.
3.  **Manual Verification**: For cases where the section is completely missing, identify the nearest relevant content in the book.
